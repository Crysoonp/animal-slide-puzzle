# 動物スライドパズル

かわいい動物写真を使った、スマートフォン対応のスライドパズルです。

## 現在のバージョン

Ver.1.0.0

## 主な機能

- おまかせ、わんこ、にゃんこ、ほかの動物モード
- 初級、中級、上級、超級
- タップ操作とフリック操作
- 完成図表示
- 番号ヒント
- 移動回数とクリア時間
- 難易度別のベスト記録
- BGM、効果音、音量設定
- スマートフォン対応

## 遊び方

1. 遊びたい画像モードを選択します
2. 難易度を選択します
3. 「ゲーム開始」を押します
4. 空白に隣接するタイルをタップ、または空白方向へフリックします
5. 写真を完成させるとクリアです
